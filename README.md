# TS Studio

TS Studio — настільний додаток для керування фітнес-студією, розроблений у рамках навчального проєкту з програмної інженерії.
Програма призначена для роботи з користувачами, тренуваннями, подіями та абонементами студії.

## Основні можливості

У програмі передбачено декілька ролей користувачів:

- адміністратор;
- тренер;
- клієнт.

Користувач може:

- зареєструватися та увійти до системи;
- переглядати свій профіль;
- переглядати розклад тренувань;
- переглядати події студії;
- записуватися на тренування;
- скасовувати запис на тренування;
- записуватися на події;
- скасовувати запис на події;
- переглядати інформацію про свій абонемент.

Адміністратор додатково може:

- переглядати список користувачів;
- переглядати детальну інформацію про користувача;
- видавати користувачам абонементи;
- редагувати інформацію про абонемент;
- видаляти абонемент;
- створювати тренування;
- редагувати тренування;
- видаляти тренування;
- переглядати учасників тренування;
- створювати події;
- редагувати події;
- видаляти події;
- переглядати гостей, записаних на подію.

## Технології

Проєкт розроблено з використанням:

- C#
- .NET
- WPF
- Entity Framework Core
- SQLite
- Material Design in XAML Toolkit
- Git та GitHub

Для зберігання даних використовується локальна база даних SQLite.

## Запуск програми

Готова версія програми доступна у розділі Releases цього репозиторію.

Для запуску:

1. Відкрити розділ Releases.
2. Завантажити файл publish.zip з останнього релізу.
3. Розпакувати архів у зручне місце.
4. Запустити файл TS_2.exe.

Програма працює локально та використовує базу даних SQLite.

## Облікові записи для перевірки

Для демонстрації роботи програми у базі даних передбачені тестові користувачі з різними ролями.

Адміністратор:

Логін: admin
Пароль: admin123

Тренери та клієнти також додані до тестової бази даних для перевірки основного функціоналу програми.

## База даних

У програмі використовується SQLite.

База даних містить інформацію про:

- користувачів;
- абонементи;
- активні абонементи користувачів;
- тренування;
- записи на тренування;
- події;
- записи користувачів на події.

Дата та час у відповідних таблицях зберігаються у текстовому форматі, що відповідає реалізації поточної версії програми.

## Навігація

Інтерфейс програми містить основне меню для переходу між розділами:

- Головна
- Розклад
- Події
- Абонементи
- Адмін-панель

Для переходу між переглянутими сторінками також передбачена навігація вперед та назад.

## Примітки

Цей проєкт є навчальною розробкою, створеною для демонстрації навичок роботи з C#, WPF, Entity Framework Core, SQLite та побудови клієнтського застосунку з ролями користувачів.

Онлайн-оплата, SMS-повідомлення та інші зовнішні сервіси у поточній версії не реалізовані.

## Версія

Поточна версія програми доступна у GitHub Releases.

Файл publish.zip містить опубліковану версію застосунку, необхідні файли для його запуску та виконуваний файл TS_2.exe.
